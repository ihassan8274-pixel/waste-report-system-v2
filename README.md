# نظام محضر الهالك - رفع على الإنترنت

نسخة كاملة جاهزة للنشر على الإنترنت. تعمل مع قاعدة بيانات **مخزنة بشكل دائم** (لن تُفقد بياناتك عند إعادة التشغيل).

## 🚀 أسهل طريقة (Railway - مجاني)

1. سجّل في: https://railway.app (باستخدام حساب Google)
2. اضغط **New Project** ← **Deploy from GitHub**
3. ارفع هذا المجلد على GitHub (أو اسحبه مباشرة)
4. Railway سيكتشف `railway.json` و `Dockerfile` تلقائياً
5. اضغط Deploy وانتظر دقيقتين
6. سيُعطيك رابطاً مثل: `https://your-app.up.railway.app` — افتحه واستخدمه

## ☁️ الطريقة الثانية (Render - مجاني لكن بدون تخزين دائم مجاناً)

1. سجّل في: https://render.com
2. **New** ← **Blueprint** ← اربط GitHub
3. سيقرأ `render.yaml` تلقائياً
4. انتبه: **التخزين الدائم يتطلب خطة مدفوعة** على Render، أما على Railway فهو مجاني

## 🖥️ الطريقة الثالثة (سيرفر خاص / VPS مع Docker)

على أي سيرفر Linux (أو حتى كمبيوتر يعمل دائماً):

```bash
docker compose up -d
```

سيعمل النظام على المنفذ 3000. البيانات محفوظة في مجلد `waste-data` ولا تُفقد.

## 🔌 الوصول إلى النموذج من الجوال / الفروع

- افتح رابط التطبيق من أي جهاز أو جوال
- أنشئ مستخدمين لكل فرع من **المستخدمين** (دور "مدير فرع" أو "موظف")
- كل الفروع تشترك في نفس قاعدة البيانات = مزامنة فورية

## 🔐 الدخول الافتراضي

- المستخدم: `admin`
- كلمة المرور: `admin123`

**غيّر كلمة المرور فوراً** من إعدادات المستخدمين بعد أول دخول.

## 📂 محتويات المجلد

| الملف | الوظيفة |
|---|---|
| `Dockerfile` | إعداد الحاوية (يعمل في أي منصة) |
| `docker-compose.yml` | تشغيل محلي/سيرفر بأمر واحد |
| `railway.json` | إعدادات Railway |
| `render.yaml` | إعدادات Render |
| `server.js` | الخادم والـ API |
| `database.js` | قاعدة البيانات (SQLite) |
| `public/index.html` | الواجهة الموحدة |
